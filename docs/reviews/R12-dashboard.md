## Invariants confirmed

- **Guards.** Every `/dashboard/*` and `/admin/*` route (32 probed live) is behind `RequireSession`; `/admin/*` additionally `role=admin` (403 for a customer session) and `RequireAdminMFA` (admins without TOTP are bounced to setup; nil auth service = skipped only in tests). The chi group `NotFound` handlers sit inside the guarded groups. No `/admin` route is mounted outside the group (P0 check: none).
- **CSRF** on every mutation in both groups (matrix above); tokens are 256-bit random, `HttpOnly`, `Secure`, `SameSite=Lax`; htmx adds the header from the meta tag.
- **Templates.** `html/template` everywhere; **zero** uses of `template.HTML`/`JS`/`URL`/`CSS`/`HTMLAttr` or `text/template` in scope (grep). Every user-controlled value seen — bucket names, object keys (`{{.Key | urlquery}}` in URLs), display names, abuse reporter fields and the reported URL (`href="{{.Report.URL}}"`, `javascript:` becomes `#ZgotmplZ`), support notes (`white-space:pre-wrap`, escaped), tenant names/e-mails, waitlist source, `intent_room` (also whitelisted by `vibeFromRoom`/`cleanRoomName` before it reaches the template), the OTP data URL inside `<script>` (JS-string escaped) — renders escaped. The generated `house.html` contains exactly one action, `{{.Name}}`; `build.py` injects only build-time constants (sprites, prices), never request data. Flash messages travel in a cookie as `url.Values` and are rendered escaped.
- **Cookies.** `vaultaire_session` HttpOnly/Secure/Lax, 24 h fixed (no sliding, no idle timeout, no remember-me); `mfa_pending` 5 min; `oauth_state` 10 min single-use; `csrf_token` session-length; `onboarding_dismissed` 1 y. Logout deletes the server row and clears the cookie ✔. Password change revokes other sessions ✔, password reset (web) all sessions ✔ (API path fixed here).
- **Client IP** everywhere in scope comes from `internal/clientip` (`middleware.ClientIP`, `api.extractClientIP`, `audit.WithRequest` in `requestIDMiddleware`) ✔. Note for local proofs: without HAProxy the last `X-Forwarded-For` entry IS the peer, so a client-set header steers the limiter locally; in prod HAProxy appends the real peer last (R1-01/R1-20 design), which is what the limiter keys on.
- **Rate limits.** Login/2FA 5/min per IP; forgot/reset 5/min per IP + 3/h per e-mail; abuse 5/min per IP; waitlist 10/h per IP (bounded map); management 100/min per tenant. New: register 10/min, API auth routes 5/min, account lockout.

- **Session revoke** checks ownership by listing the user's sessions first; the current session cannot be revoked from the table (use logout) ✔.
- **Static assets** are all referenced through `{{asset}}` (`assets_test.go` guards it); fonts are self-hosted; htmx 2.0.4 is vendored; the only CDN script is the QR generator (R12-23).

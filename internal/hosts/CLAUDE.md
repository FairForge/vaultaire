# internal/hosts — the one host source (WP-DOMAIN-1, F-17)

Every host name the product prints or matches comes from here; nothing else types a domain into code, templates, guides or the landing sources (`internal/api/host_stale_test.go` fails when something does). Leaf package (zap only): `internal/api`, `internal/dashboard`, `internal/docs`, `internal/email`, `internal/sitestats` and `internal/api/landing` read it. Pattern: `internal/api/landing/prices.go` (one source, `Get()`, tokens for hand-written copy).

- `Hosts{Canonical, S3, CDN, Trust, Docs, Status, App, BaseURL, Aliases}` — origins are `scheme://host[:port]` without a trailing slash; aliases are bare names.
- `FromEnv(getenv, port, logger)` reads `VAULTAIRE_PUBLIC_HOST`, `VAULTAIRE_ENDPOINT`, `VAULTAIRE_BASE_URL`, `CDN_PUBLIC_HOST`, `TRUST_PUBLIC_HOST`, `DOCS_PUBLIC_HOST`, `STATUS_PUBLIC_HOST`, `APP_PUBLIC_HOST`, `VAULTAIRE_ALIAS_HOSTS`. Malformed = Warn + default (an alias is dropped on its own; one naming the canonical or S3 host is dropped as a redirect loop). Fallbacks keep a deploy before the `.env` edit identical to before: Canonical ← `VAULTAIRE_BASE_URL` ← `http://localhost:PORT`; S3 and BaseURL ← Canonical; CDN ← `https://cdn.<canonical host>` when that host is a public name, else Canonical (served under `/cdn/`); Trust ← `https://trust.<canonical host>` the same way (K4b), else Canonical; Docs ← `https://docs.<canonical host>` the same way (WP-DOMAIN-1 part 3A), else Canonical (served under `/docs`); Status ← `https://status.<canonical host>` the same way (part 3B), else Canonical (its `/status` page); App ← `https://app.<canonical host>` the same way (part 3C), else Canonical.
- `NewServer` calls `FromEnv` then `Set`; everything else calls `Get()` (Defaults(8000) when nothing was set — unit tests). Pure functions take a `Hosts` (`securityTxtBody`, `llmsTxtBody`, `GenerateOpenAPISpec`, `landingPages`, `renderDocsPages`) so tests pin values without the global.
- `IsAlias`, `IsS3Host` (`s3.<canonical | alias | brand | legacy>` and the S3 endpoint's own host — never redirected), `IsCDNHost` (dedicated CDN host, `cdn.<canonical | alias>`, and `cdn.stored.ge` / `cdn.stored.cloud` always), `CDNBase()` (URL prefix + `slug/bucket/key`), `IsTrustHost` (K4b, RP35-1: the `TRUST_PUBLIC_HOST` host, `trust.<canonical | alias>`, and `trust.stored.cloud` / `trust.stored.ge` always), `TrustPublic()` (the canonical origin is a public name: the transparency log's read side answers on a trust host only — `internal/api/translog_read.go`), `TrustHost()`, `IsDocsHost` / `DocsHost()` / `DocsPublic()` (part 3A: `IsTrustHost`'s rule with `docs.`; the docs host's closed list is `internal/api/docs_host.go`), `DocsBase()` (the prefix every printed docs link is built on — `__HOST_DOCS_BASE__`, the landing's `{{.Docs}}`; **live since 2026-11-02**: `Docs` whenever the docs host is a host of its own, else the canonical `/docs`; `DocsFlipped()` says which), `IsStatusHost` / `StatusHost()` / `StatusPublic()` / `IsStatusOrigin` (part 3B: `IsTrustHost`'s rule with `status.`; the page is the Worker `edge/status`, which never reaches the origin — a status name that does is `internal/api/status_host.go`'s 301 / 404), `IsAppHost` / `AppHost()` / `AppPublic()` (part 3C: the rule with `app.`; the dashboard's own host, `internal/api/app_host.go`), `AppBase()` (the origin printed dashboard links are to be built on — **dark**: the canonical origin until the owner's proof, then one line moves it to `App`), `IsWebHost` (Stage 1a Prompt 39: where a browser's page view is answered as a website — the canonical host, an alias, `stored.cloud` / `stored.ge` / `stored.pics` and `www.` of each whatever the env says; never an S3, CDN, trust, docs, status or app host — `internal/api/web_host.go`), `IsOwn` (referrer statistics, sign-up attribution), `Domain()` (canonical host, or `stored.cloud` for a development origin — an address is never at localhost), `SupportEmail` / `SecurityEmail` / `AbuseEmail`, `URL(path)`, `Tokens()` / `Expand` (`__HOST_S3__`, `__HOST_S3_HOST__` — the bare host, Kopia's `--endpoint` — `__HOST_DOCS_BASE__`, `__SUPPORT_EMAIL__`, … in the docs guides).
- `BrandName = "Stored"`, `BrandDomain = "stored.cloud"`, `LegacyDomains = stored.ge, stored.pics` (aliases served forever).

`Hosts.Legal()` (WP-PAY-3, D-P20-A1) is the ONE source of the issuer's legal data — `LegalEntity{Name: "FairForge LLC", AddressLines, Jurisdiction: "State of Utah, United States", Email: support@<Domain>}` — read by the receipt page and the receipt mail. The repository holds no street address: `AddressLines` is the jurisdiction until the owner adds one here. The legal templates (`dashboard/templates/legal/*.html`) keep their own copy for now.

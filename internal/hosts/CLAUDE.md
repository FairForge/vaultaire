# internal/hosts — the one host source (WP-DOMAIN-1, F-17)

Every host name the product prints or matches comes from here; nothing else types a domain into code, templates, guides or the landing sources (`internal/api/host_stale_test.go` fails when something does). Leaf package (zap only): `internal/api`, `internal/dashboard`, `internal/docs`, `internal/email`, `internal/sitestats` and `internal/api/landing` read it. Pattern: `internal/api/landing/prices.go` (one source, `Get()`, tokens for hand-written copy).

- `Hosts{Canonical, S3, CDN, BaseURL, Aliases}` — origins are `scheme://host[:port]` without a trailing slash; aliases are bare names.
- `FromEnv(getenv, port, logger)` reads `VAULTAIRE_PUBLIC_HOST`, `VAULTAIRE_ENDPOINT`, `VAULTAIRE_BASE_URL`, `CDN_PUBLIC_HOST`, `VAULTAIRE_ALIAS_HOSTS`. Malformed = Warn + default (an alias is dropped on its own; one naming the canonical or S3 host is dropped as a redirect loop). Fallbacks keep a deploy before the `.env` edit identical to before: Canonical ← `VAULTAIRE_BASE_URL` ← `http://localhost:PORT`; S3 and BaseURL ← Canonical; CDN ← `https://cdn.<canonical host>` when that host is a public name, else Canonical (served under `/cdn/`).
- `NewServer` calls `FromEnv` then `Set`; everything else calls `Get()` (Defaults(8000) when nothing was set — unit tests). Pure functions take a `Hosts` (`securityTxtBody`, `llmsTxtBody`, `GenerateOpenAPISpec`, `landingPages`, `renderDocsPages`) so tests pin values without the global.
- `IsAlias`, `IsS3Host` (`s3.<canonical | alias | brand | legacy>` and the S3 endpoint's own host — never redirected), `IsCDNHost` (dedicated CDN host, `cdn.<canonical | alias>`, and `cdn.stored.ge` / `cdn.stored.cloud` always), `CDNBase()` (URL prefix + `slug/bucket/key`), `IsOwn` (referrer statistics, sign-up attribution), `Domain()` (canonical host, or `stored.cloud` for a development origin — an address is never at localhost), `SupportEmail` / `SecurityEmail` / `AbuseEmail`, `URL(path)`, `Tokens()` / `Expand` (`__HOST_S3__`, `__SUPPORT_EMAIL__`, … in the docs guides).
- `BrandName = "Stored"`, `BrandDomain = "stored.cloud"`, `LegacyDomains = stored.ge, stored.pics` (aliases served forever).

`Hosts.Legal()` (WP-PAY-3, D-P20-A1) is the ONE source of the issuer's legal data — `LegalEntity{Name: "FairForge LLC", AddressLines, Jurisdiction: "State of Utah, United States", Email: support@<Domain>}` — read by the receipt page and the receipt mail. The repository holds no street address: `AddressLines` is the jurisdiction until the owner adds one here. The legal templates (`dashboard/templates/legal/*.html`) keep their own copy for now.

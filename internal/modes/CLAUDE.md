# internal/modes

Keystone K3 (Stage 1a Prompt 26; plan Phase 41.0; `docs/ARCHITECTURE_CONTRACT.md` lines 1, 3, 8). The bucket's **mode** — Private / Standard / Public — and the one table that says what each lets us read.

- **The table** is `internal/api/landing/modes.json` (embedded by `landing.ModesJSON()`, beside `prices.json`): exactly three modes in the order private, standard, public — each `id`, `name`, `server_holds` (what we can read), `customer` (the customer's sentence), `how` (how a bucket gets it) — and `surfaces` (developer: standard + private; consumer: standard until F-19, then private; public: public). A sentence is `{text, requires_master_key, without_master_key}`: one marked `requires_master_key` (Standard's "encrypted at rest with keys we hold") renders only while the process has the master key — `Sentence.Render(MasterKeyLoaded())`; `SetMasterKeyLoaded(true)` is called by `api.NewServer` once the tenant key store starts. Prod has no master key (`docs/reviews/K3-PROBE.md`): the pre-key sentence is what renders there.
- `All()` parses and `Validate`s once (a failure panics: the file is in the binary); `Get(id)`, `Name(id)`. Validation: three modes, every name and sentence non-empty, a pre-key sentence wherever one needs the key, no mode named Vault (a tier), no "zero-knowledge" anywhere. Tests `TestModesJSON_ThreeModesNoForbiddenWords`, `TestValidate_RefusesWhatTheTestRefuses`, `TestSentence_RenderFollowsTheMasterKey`.
- **The column** `buckets.mode` (migration 102) is GENERATED from `visibility` and `ssec_required`; `FromColumns` is its CASE in Go. **NAME TRAP:** `visibility = 'private'` means "not public-read" = **Standard**.
- **The one write door** `SetBucket(ctx, q, tenant, bucket, Change{Visibility, SSECRequired})`: one UPDATE that writes either column and refuses public + ssec (the 096 rule, against the row's values after the change) — `ErrPublicSSEC` / `ErrNoBucket` / `ErrBadVisibility`, nothing written on a refusal; returns the new mode. Callers: the dashboard bucket settings (`bucket_settings.go`, with the rest of the form in one transaction) and the management PATCH (`management_routes.go`). A create (three INSERTs: `bucket_create.go`, `auth/backfill.go`, the `_exports` row) is born Standard. `TestBucketModeWritersOnlyThroughTheDoor` reads every non-test Go file and fails on any other SQL that writes either column. Tests `TestBucketMode_DerivedFromVisibilityAndSSEC` (all four combinations, the refused one included), `TestSetBucket_*`.
- **Never typed elsewhere:** `internal/api/modes_copy_test.go` `TestModeNamesOnlyFromModesJSON` fails on a modes.json sentence, "<name> mode", "keys we hold" or "zero-knowledge" typed in a dashboard template, a landing source, a served guide, the OpenAPI generator or llms.txt, and on a `>Private<` / `>Public<` label — with an explicit, counted allow-list (`modeCopyAllowed`; an entry that matches nothing fails too). The legacy visibility labels of the bucket list and settings are on it until `modes_copy` renders `modes.Name`.

01Pricing

Pay per TB. That's the whole model.

You buy a quota in whole TB at a flat per-TB rate and resize it whenever you like (prorated). The bill never moves on its own: no meters, no overage, no API fees, no request classes, no retrieval surcharges. Every number below comes from one price file; this page is built from it.

03What is charged, and what never is

The quota you buy. Nothing else.

Never charged

  • API calls and requests, of every kind
  • Downloads inside your allowance
  • Vault restores (they draw on the same allowance)
  • Retrieval fees, request classes, minimum object sizes

The egress allowance

One allowance for the account each UTC month: __EGRESS_STD__× your Standard quota plus __EGRESS_VAULT__× your Vault quota.

__EGRESS_PAST_LONG__

__EGRESS_ONE__

What is charged

  • The quota, in whole TB, at the tier's rate for the period you chose
  • Past the allowance nothing is billed: downloads slow down until the 1st (UTC). There is no per-GB rate today
  • A write past the quota is refused with a clear error until you resize; there is no overage

Uploads through the edge

A single upload request is limited to 100 MB: that is Cloudflare's request limit, and a larger one is answered with an HTML 413 before it reaches us. Every S3 tool sends a large file as a multipart upload; keep the part size under 95 MB (64 MB is a good choice). The FAQ has the settings.

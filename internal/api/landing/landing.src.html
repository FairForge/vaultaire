03Connect

If it speaks S3, it works.

Most backup apps, sync tools and code libraries already speak S3. Give them our address and your keys. A few favourites:

Copy, sync, mount

Sync a folder, mount a bucket as a drive, or move everything over from another provider in one command. Walkthrough in the rclone guide.

shell
rclone config create stored s3 provider=Other \
  access_key_id=YOUR_KEY secret_access_key=YOUR_SECRET \
  endpoint={{.S3}} region=us-east-1

rclone sync ~/photos stored:photos -P      # keep in sync
rclone mount stored:photos ~/mnt/photos    # use as a drive
rclone sync b2:old-bucket stored:photos    # leave your old provider

Encrypted backups

Encrypted on your machine before upload, deduplicated, incremental. Your password never leaves your computer, so we store bytes we cannot read.

shell
export AWS_ACCESS_KEY_ID=YOUR_KEY
export AWS_SECRET_ACCESS_KEY=YOUR_SECRET

restic -r s3:{{.S3}}/backups init
restic -r s3:{{.S3}}/backups backup ~/Documents
restic -r s3:{{.S3}}/backups snapshots

Drag and drop

Any S3 app works: Cyberduck, Mountain Duck, S3 Browser, Transmit. Add a connection with these settings, then drag files in. No terminal needed.

connection settings
Protocol:   Amazon S3
Server:     {{.S3Host}}
Port:       443
Access Key: YOUR_KEY
Secret Key: YOUR_SECRET

Scripts and cron jobs

The flags you already know, plus --endpoint-url.

shell
alias s3st='aws --endpoint-url {{.S3}}'

s3st s3 mb s3://ci-artifacts
s3st s3 cp build.tar.gz s3://ci-artifacts/v1.4.2/

Any AWS SDK

Python, JavaScript, Go, Rust, PHP: set the endpoint, everything else is stock. No SDK of ours to install, and no lock-in to us.

python, boto3
import boto3

s3 = boto3.client(
    "s3",
    endpoint_url="{{.S3}}",
    aws_access_key_id="YOUR_KEY",
    aws_secret_access_key="YOUR_SECRET",
)
s3.upload_file("report.pdf", "my-bucket", "2026/report.pdf")

Also built in: version history, Object Lock (WORM), presigned links, scoped keys, webhooks and public buckets. Read the docs.

05Straight answers

Questions, answered plainly.

More in the full FAQ.

What does S3-compatible mean?

S3 is the storage language most backup apps, sync tools and code libraries already speak. If an app can save to Amazon S3, it can save to Stored: give it our address and your keys.

Standard or Vault?

Standard for files you open. Vault for copies you hope never to need: it is tape, so a restore takes minutes to start. Most people use both, and you can change the split any time.

Where does my data actually live?

With established storage providers: enterprise S3 infrastructure for Standard, professional tape libraries for Vault. The control plane runs on our own hardware with daily database backups; your data doesn't depend on that one box.

What if you disappear?

It's standard S3: rclone sync your data out any time, free, no proprietary format. We commit to at least 60 days notice and free unlimited downloads. The engine is open source, so the software outlives us too.
